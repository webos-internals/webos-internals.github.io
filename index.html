Where to start

The wiki is large and was written over many years. These are the doors most people came in through.

Start here webOS Archive The living hub for legacy webOS: the restored app catalogue, the SDK and developer tools, active forums and Discord. If you want software to install on a device, or people to ask, go there first. What follows on this site is the reference material behind it — how the system works and how to change it. webosarchive.org
Getting started The paths into modifying a Pre, depending on how far you want to go. Preware The homebrew package manager: patches, apps and kernels from community feeds. Patches Modifications to the stock interface that add features Palm left out. Accessing Linux Getting a root shell and working with the Linux system under webOS. Linux applications The Optware catalogue, compiled and packaged to run on the device. webOS 2 upgrade Putting webOS 2.1 on a Pre or Pre Plus that never officially received it.
